# 仍可发现的信息

[English](remaining-exposure.md) | 简体中文

保护版并非完全不透明。本页说明 Linux 测量中的剩余信息及“敏感语料零命中”的实际含义。
精确计数和时间见[实测对比](comparison.zh-CN.md)，机器可读摘要见 [comparison.json](comparison.json)。

## 当前测量如何解读

声明语料在 baseline 命中 71 次、仅 strip 后 23 次、组合保护后零次。
这是匹配次数，不是独立秘密数量，也不是完整保密证明。protected-only 策略基准仍约 2.6 ms，
微小差异不构成性能提升证据。

heavy 约为 baseline 策略循环的 17 倍，mixed VM 约 30 倍，仅适用于选定的 500,000 次策略负载，
不能外推整个科学应用。独立数值循环没有混淆，因此不建议对所有函数使用 VM 或激进 CFG 改写。
protected 安装产物约 62.5 kB，stripped-only 约 54.3 kB，mixed VM 约 300 kB，均不含动态系统库及 libsodium。

## 有意保留的信息

| 证据 | 保留原因 | demo 的处理 |
| --- | --- | --- |
| `ar_create`、`ar_destroy`、`ar_type`、`ar_throw`、`ar_compute` | 主程序需要的公开 C 接口 | 不隐藏；保护版 ELF 库仅导出这五项 |
| C++ 运行库、libc、加密导入 | 动态加载及正常执行 | 不隐藏，与内部源码标签分别处理 |
| `libengine.so`、`libsodium.so`、系统 DLL 名称 | 加载器/依赖身份 | 不属于声明语料的隐藏目标 |
| 不透明 `65R...` RTTI 字符串 | 保持类型身份 | 隐藏内部原名，保留 RTTI 记录和布局 |
| 公开严重级别和诊断 ID | 运维及离线恢复 | 保留标签；模板和字段封装加密 |
| 编译器版本及公开 LLVM URL | `.comment` 元数据 | 本 demo 未移除；不等于私有源码根目录 |
| `/lib64/ld-linux-x86-64.so.2` | Linux 加载器 | 系统路径，保留 |
| `/proc/self/exe` | 相对可执行文件定位资源 | 有意使用，保留 |
| `$ORIGIN` | 可搬迁安装库搜索路径 | 保留，替代绝对构建目录 |
| 不透明 `R-...dat` 及系数内容 | 安装资源 | 隐藏文件名语义，不加密内容 |
| 算术、控制流、内存访问 | 可执行功能 | 仅选定函数混淆，仍可观察 |

## 有意展示的限制

`rtti` 命令还打印普通分派说明。它不在诊断目录内，在 `protected` 中为明文；
混淆配置的 xollvm 模块级字符串处理隐藏其静态表示，但运行时仍会解密打印。
这展示了它与公钥诊断保密的差别，不能据此声称全程序日志受保护。

仅 strip 仍保留诊断和 RTTI 内容，也可能保留导出的全局变量名。保护版组合多种机制。
当前发布门禁扫描 EXE 和示例库中的选定敏感消息、类/函数/全局名称及第一方源码基名，
同时拒绝安装产物含实际开发项目根目录。

路径清单区分 URL 和文件系统路径。机器码或密文可能偶然形成可打印路径，因此路径候选需上下文审阅。
必要系统路径应记录理由，不应盲目替换。

## 私有产物与发布包

未 strip 构建程序仍可能含原始修饰函数/类型符号，即使运行时 RTTI 初始化字符串已经改变。
构建 RUNPATH 也可包含构建目录；中间 IR 有意保留调试元数据，映射保留原类型和诊断位置。

这些文件属于私有开发材料。安装副本单独 strip 和审计，不安装私有映射、密钥、IR 或 PDB。
不能将构建目录压缩包当作发布包。Windows 应单独执行原生 PE/PDB 流程，Linux 观测不能证明 Windows 包干净。

## 分析人员仍能做什么

可检查虚表和异常机制、识别标准库行为、跟踪输入输出、观察内存普通明文、从指令重建部分算法。
公开 demo 密钥使读者可解密 demo 警告；私有密钥诊断也无法隐藏加密前被调试器观察到的字段。
项目减少选定的直接信息暴露，并提供开发者恢复流程；它不是 DRM、反调试系统或不可逆向证明。

[Windows 原生验证](windows-validation.zh-CN.md)已对一个 VM-light 函数完成动态辅助恢复：
REA/Frida 结合处理器分析和专用解码，将其还原成等价 C++，4360 个不同输入匹配。
这是具体样本的恢复证据，不是通用自动去虚拟化能力。
